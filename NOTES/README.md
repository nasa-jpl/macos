# NOTES/ — session hand-off notes

Short, dated summaries of what a work session did — for the CCL lane, the
next session, or another committer picking up the thread.

**Naming:** `TO_CCL_<YYYY-MM-DD>_<HHMM>.md` (local time). One file per
hand-off; do not overwrite older notes (they are the trail).

**Scope:** what landed, where (repo + branch + commit), what was gated,
what is open, and any provenance/review caveats. A note is a summary, not
a source of truth — the packets (`REVIEW_*.md`), `CURRENT_SLICE.md`, and
the git history remain authoritative.

These are developer-facing files: they live on `dev` and are stripped from
`main` at public release, per the branch model in `CLAUDE.md`.
