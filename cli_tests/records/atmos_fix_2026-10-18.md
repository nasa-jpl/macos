# ATMOS fixed, placed, and reconsidered -- 2026-10-18 (PLAN_CONSOLIDATION 1.2 (p), Dave's ruling)

Follows `atmos_kolmogorov_check_2026-10-18.md` (the generator and the RNG are right; what the rays receive
is wrong).  Every number below is from the CLI on the manual's Cassegrain (4 m, 51-px ray grid, dx 0.08 m,
EFL 22.4736 m), r0 0.25 m at 1e-6, tilt participation 1, unless named; ifx and gfortran print the same
values to the last digit after the fix.  Gates: `cli_tests/cmd/ATMOS_seed.jou`, `ATMOS_placement.jou`,
the arithmetic in `cli_tests/tools/atmos_map_check.py`.

## 1. The defect: `RFOURN`'s declaration (sunsub.F), not the coupling

`RFOURN` is Numerical Recipes' `fourn`: it indexes `DATA` as interleaved (re, im) REALs (`IP1 = 2*NPREV`,
`DATA(I3+1)` = imaginary).  019a2981 (2023-11-19, the module clean-up) added `COMPLEX*8 DATA`, so every
index addressed a whole complex element: the transform ran to 2 x NTOT -- WRITING past the end of the
caller's array -- and returned garbage.  That one line is the checkerboard (lag-1 D 122x Kolmogorov,
adjacent-increment correlation -0.68), the 1e5 seed-dependent amplitude, ifx's run-to-run non-determinism
under a fixed seed (the out-of-bounds write lands in whatever follows CD2) and "every ray lost at a
Reflector" (rays thrown off the primary).  Fix: `REAL*4 DATA` (what the implicit type was before 2023).
The emulation of 7eda382b used a correct FFT, which is why it reproduced the routine's intent and not the
engine.  `RFOURN`'s only other caller is `linsub.F`'s LPI (the legacy linear-model PSF): fixed with it.

SEED was always honoured (`AddAtmos` passes `NoiseSeed(2)` to `AtmosPhase`, `GAUSS` advances it); the
three different runs of the 10-17 journal were UNSEEDED (the start-up seed is time-based) -- by design --
plus ifx's out-of-bounds write.  Now `seed n; atm; opd 1` prints the same RMS twice in a session and on
both compilers (7.337653537D-07 / 1.200690873D-06 / 2.736065294D-06 for 12345 / 4321 / 777).

## 2. Two coupling defects, fixed

- **The 3x tilt.**  `C1 = 0.5/dx` was the one-row central difference; the stencil sums three rows.
  Now `C1 = 1/(6 dx)`.  Measured: spot = C x grad W with C/EFL 2.94 pre-fix, 0.980 post (both axes,
  R^2 1.00000).  (0.98, not 1.00: the regressor is the engine's own smoothed stencil applied to the
  exit-pupil map; the residual 2 % is the converging-beam geometry, below the 10 % gate.)
- **`ztdir = 0`** (the direct `WFElt *= exp(i k R)` multiply) is LEFT disabled: the field downstream is
  built from the ray OPLs, which already carry the screen (`CumRayL`); enabling it would count it twice.

Measured, not changed: the piston/tilt-removal disk is `nradius = nGridPts` (the grid WIDTH, twice the
routine's documented aperture radius).  Over 24 seeds the piston-removed and tilt-removed screen
variances are 1.06 and 1.08 x Noll's 1.030 and 0.134 (D/r0)^(5/3) (sampling error ~20 %), so it does no
measurable harm; left alone.

## 4. Placement (Dave: "a Reference surface only?")

Measured: the element TYPE does not matter.  The RAY-grid screen is sampled by ray-grid INDEX and tilts
the rays along xGrid / yGrid (the source frame), so it is right exactly where the ray grid at the element
is still the source grid:

| element | accepted | spot C/(focal length) | note |
|---|---|---|---|
| Cassegrain 1, entrance Obscuring | yes | 0.980 | the pupil |
| Cassegrain 2, Primary (Reflector) | yes | 0.95 (R^2 0.9996) | curved, at the pupil |
| Cassegrain 3, Secondary (Reflector, converging beam) | yes | 0.965 (R^2 0.99999) | screen pitch = the ray spacing there |
| Cassegrain 4, exit-pupil Reference | yes | -- | |
| periscope 1, before the folds | yes | 0.981 (f = 10 m) | `ZGD_test_files/tst_atmos_fold.in` |
| periscope 3, BETWEEN the folds | **refused** | pre-fix: x axis 1e-8 vs 7e-5 | xGrid lies along the beam |
| periscope 5, after the folds | yes | 0.980 | the pair restores the frame |

Rule (in `AddAtmos`, before the RNG is touched): fit the ray-grid vectors from the ray positions on the
element (least squares, position = p0 + i a + j b over the valid rays) and the mean outgoing direction;
refuse by name unless a is within 1 degree of +xGrid, b of +yGrid, and the beam within 1 degree of
perpendicular to both.  It catches a fold, an image rotation and an inversion (after an intermediate
focus a and b reverse).  The message says why and names the way out: a pupil before the first fold, or
the ATMospheric-grid option, which places the screen in the element's local beam frame (measured
between the periscope's folds: both axes respond, spot ~1.1 f x grad -- not yet gated, see 5).

## 5. The model, reconsidered (for Dave)

**What it IS (now).**  A single thin phase plate applied once, at one element, after the trace reaches
it: Colavita's FFT Kolmogorov screen (`screenle`), sampled at the ray spacing there, piston and tilt
removed and Noll's tilt re-added x pTilt; phase in rad at the r0 wavelength, converted to OPD by
lambda/2pi (achromatic OPD -- right for turbulence, and r0 then scales as lambda^(6/5) by itself).  Each
ray's OPL changes by -R and its direction by -grad R: the geometric-optics model of a phase plate, and
it is Malus-consistent -- the exit-pupil wavefront equals the screen (corr 1.000000) and the transverse
aberration equals -EFL grad W.  "Phase without tilt" is therefore not the current state: the tilt is
there and agrees with the phase.  Diffraction (INT / PIX) sees the screen through the ray OPLs.

**Where it is physical.**  A single layer conjugate to the plane where it is placed, i.e. ground-layer
or pupil-conjugate turbulence, with an infinite isoplanatic patch: the screen is attached to the ray-grid
INDEX, so every field point sees the same screen.  That is the standard short-exposure, single-conjugate
model and is what the RAY option should be called.

**What it is not, and what a physical non-pupil (altitude) screen would need.**
1. *Anisoplanatism.*  A layer at altitude h is seen by field angle theta shifted by h theta.  Neither
   option does it: RAY indexes by grid, and the ATMospheric grid positions rays relative to the CHIEF
   ray (`CRSpot = RayPos - crLocalPos(chief)`), which removes the shift.  Needs: positions from a fixed
   origin on the element, and a screen larger than the union of the field's footprints.
2. *Scintillation.*  A screen away from the pupil changes the amplitude downstream by Fresnel
   propagation.  Rays cannot carry that; it needs the screen to multiply the FIELD at its plane (the
   dead `ztdir` path) with a near-field propagation onward, and then NOT also enter the ray OPL.  The
   right coupling depends on the propagation type after the element -- today only the ray route exists.
3. *Layers.*  More than one screen = several plates with propagation between; the command applies one
   per call and a later trace from the source discards it.
4. *Time.*  One frozen realization per call; Taylor frozen flow would shift the screen per step.
5. *Scales.*  No power beyond N dx (20 m at model 256) except the re-added tilt; no power below the
   ray spacing.  The ensemble is Kolmogorov to 6 % at 1-8 px; the 2 % tilt-scale residual is geometry.

**Recommendation.**  Keep RAY as the pupil-conjugate single-layer model -- now correct, deterministic
under SEED, and refused by name where it cannot work.  Treat the ATMospheric grid as the route to
non-pupil placement; before it is trusted it needs (a) positions from a fixed origin (anisoplanatism),
(b) its own carry/tilt gate (the checker already does both), (c) the same `RFOURN`-era review of its
`nAtmPts` radius.  A field-multiply coupling for near-field propagation, and multiple layers, are
features: PLAN §4, after the freeze.
